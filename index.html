① 直接連線（平常用這個）

勾平台 → 按「直接連線取數」。實測平台 API 允許跨網域，瀏覽器直接打得到，不用貼腳本。記得先連 VPN。

② 之後只補未結論的

凌晨跑完會剩一些「待驗」。之後按 🔁 只重驗還沒結論的，已驗出結論的不會被重查也不會被覆蓋。

備援：取數腳本

萬一哪天直連被擋（CORS／網路），改用 F12 貼腳本取數，下載資料檔拖回來，判定結果完全一樣。

📂 把取數腳本下載的資料檔拖進來（可一次多個），或點這裡選檔
⚠️ 一定要先連 VPN。平台自 2026-09-03 起擋台灣 IP，沒連 VPN 時 API 會回 error_code 10000（HTTP 仍是 200）。本工具認得這種回應會直接停下並提示，不會產生「0 檔、全部通過」的假報表。
⚠️ 歷史只回 120 筆。分分彩一天 1440 期，只涵蓋約 2 小時，所以要在該彩種換日後 2 小時內取數，否則會是「待驗」。

② 檢驗結果

🔁 還沒結論的怎麼辦

結果會累積在這台電腦的瀏覽器裡（同一天／同一個檢驗日期）。重跑時已經有結論的彩種不會被重查、也不會被覆蓋， 只補上還沒結論的那些——所以早班重跑不會把凌晨已經驗到的結果弄丟。
取數腳本（點開可手動複製）

在該平台的網頁上按 F12 → 切到 Console 分頁 → 貼上下面整段 → 按 Enter。 跑完會自動下載一個 期號原始資料_平台_日期.json，把它拖回上面即可。六個平台各做一次。
